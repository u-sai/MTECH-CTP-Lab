This folder contains the Computational Thinking / M.Tech lab work for CO1.

## Program

- `library.py` - Sorts library accession numbers in ascending order using Merge Sort.

## Algorithm

Merge Sort follows the divide-and-conquer approach. The input is divided into smaller parts, each part is sorted, and the sorted parts are merged.

## Complexity

- Time Complexity: O(n log n)
- Space Complexity: O(n)
